# V0.3 Hardware Acceptance

Use this checklist on the主播 Windows machine. Do not record real Tencent Cloud secrets in this file.

1. Open Windows Settings and confirm microphone permission is enabled for desktop apps.
2. Close apps that may occupy the microphone, such as OBS, browser tabs, meeting software, or audio tools.
3. Set Tencent ASR environment variables in PowerShell:

```powershell
$env:TENCENT_ASR_APP_ID="your-app-id"
$env:TENCENT_ASR_SECRET_ID="your-secret-id"
$env:TENCENT_ASR_SECRET_KEY="your-secret-key"
```

4. Start Agent from `D:\git-ai-live\ai-live-edge-agent`.
5. Open `http://127.0.0.1:18081/console/index.html`.
6. Confirm microphone status is running after ASR auto start.
7. Confirm ASR status distinguishes connected, disabled, and error states.
8. Open `http://127.0.0.1:18081/renderer/index.html`.
9. Add an OBS Browser Source with that Renderer URL.
10. Set OBS browser source width and height to `1920 x 1080`.
11. Keep OBS custom CSS/background transparent.
12. Upload a real PNG in Console.
13. Upload a real GIF in Console.
14. Upload a real WebM in Console.
15. Test PNG, GIF, and WebM actions from Console.
16. Speak a real wake word plus command.
17. Confirm temporary ASR text does not trigger actions.
18. Confirm final ASR text triggers the matching action.
19. Confirm cooldown prevents repeated triggers.
20. Confirm duplicate final text debounce still works.
21. Confirm `durationMs` hides the asset automatically.
22. Confirm WebM end behavior in Renderer/OBS.
23. Record any failed item with time, observed behavior, and related Console error.
